## Deskripsi Proyek
Proyek ini merupakan *Single Page Showcase Webpage* yang memenuhi seluruh kriteria spesifikasi teknis modul praktikum Minggu 02:
1. **Struktur Semantik HTML5**: Menggunakan tag `<header>`, `<nav>`, `<main>`, `<section>`, `<aside>`, dan `<footer>` secara terstruktur.
2. **Penyajian Data Tabular & Lists**: Menyajikan tabel capaian akademik lengkap (`<caption>`, `<thead>`, `<tbody>`, `<tfoot>`, atribut `scope`) serta daftar terurut (`<ol>`) dan tak terurut (`<ul>`).
3. **Formulir Interaktif & Accessible**: Memuat lebih dari 6 jenis kontrol input (`text`, `email`, `tel`, `number`, `radio`, `checkbox`, `select`, `textarea`), dikelompokkan dengan `<fieldset>` dan `<legend>`, label eksplisit `for`, serta validasi native `required`.
4. **CSS Modern & Responsif**: Menggunakan Universal Box-Sizing Reset, aturan warna 60-30-10, Flexbox, CSS Grid, serta Media Queries untuk tampilan mobile.
